# Stretch It — Kids Guided Mode

기존 core는 수정하지 않고 `Tracker({face:false, hands:true})`, `INDEX_TIP`, 영상 좌표 변환과 smoothing을 재사용합니다. p5 없이 기본 Canvas 2D로 카메라와 그림을 합성합니다. 튜토리얼 뒤에는 얼굴+손 Tracker 한 개를 공유하는 전체 Explore 패널이 열립니다. 학생 계정·서버·파일 업로드 API는 없습니다.

## 실행 / 배포

저장소 루트에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/kids/`를 엽니다. 학생에게는 HTTPS로 배포한 `/kids/` 링크만 전달합니다. 파일을 더블클릭하는 `file://` 실행은 지원하지 않습니다.

정적 배포 파일이 필요하면 `node kids/build.mjs`를 실행합니다. `dist/` 전체를 HTTPS 정적 호스팅에 올리면 됩니다. 루트는 `/kids/`로 이동합니다. 기존 도메인의 하위 경로에도 상대 경로로 동작합니다. Sites의 비공개 미리보기는 교사용이며, 학생 배포 시 로그인 없는 공개 호스팅이 필요합니다.

## 수업 흐름

1. 카메라 허용 → 두 손 0.65초 감지 → 손 사이 거리 0.18 이상 벌리기: 성공 안내 후 자동 이동.
2. 강도 80 이상 → 반대로 → 이미지 고르기(또는 준비된 그림) → 다른 효과 고르기: 성공 후 직접 다음으로 이동.
3. 마지막 비교 단계에서 **튜토리얼 끝! 자유롭게 놀기** → Explore: 움직임 조건을 기다리지 않고 전체 컨트롤 패널로 이동합니다. 이미지와 Stretch It 설정은 그대로 이어집니다.

감지의 교육용 거리는 화면의 두 검지 끝 사이 2D 거리입니다. 손이 사라지면 성공 조건을 초기화하고 마지막 그림 상태를 유지합니다. CAMERA SEES의 손 수와 거리에는 실제 입력을 표시하며, 반대로 설정해도 입력 막대 자체는 뒤집지 않습니다.

카메라가 안 되면 **손 없이 해보기**로 동일한 수업을 진행할 수 있습니다. 데모를 별도 표시하고 두 손 대신 슬라이더를 사용합니다. **선생님 도움 → 이 단계 넘어가기**는 기술 문제용입니다. **처음부터**는 카메라를 끄고 업로드 그림·설정·수업을 초기화합니다. 다운로드 링크는 이미 만든 결과물을 잃지 않도록 남깁니다.

이미지는 브라우저 메모리에서만 사용합니다. PNG/JPEG/WebP/GIF, 10MB/32MP 이하를 받고 1200px로 축소합니다. GIF는 정지 이미지로 사용합니다. MediaPipe 런타임과 모델은 외부 CDN에서 다운로드하므로 첫 카메라 실행에 인터넷이 필요합니다. 외부 로딩이 실패해도 데모는 동작합니다.

## 저장

사진은 960×720 PNG, 영상은 3초 카운트다운 후 10초 영상(WebM, 지원 환경에서는 MP4)입니다. 무대만 저장되며 튜토리얼·버튼·카운트다운은 포함하지 않습니다. Mouth Music에서 소리를 켜면 합성 소리도 영상에 들어갑니다(마이크 녹음 없음). 다른 탭으로 이동하거나 초기화·예제 전환을 하면 진행 중 녹화를 조기 종료하여 현재까지의 결과를 저장합니다. 다운로드가 차단되면 **파일 다시 저장**을 누릅니다. Drive 업로드는 학생이 직접 합니다.

## 검증

`node kids/check.mjs` — 수업 조건·거리 범위·반전·효과 경계 검사.
`node kids/check-recorder.mjs` — 가짜 시계와 녹화 API로 카운트다운·자동 종료·사진·취소 검사.

수업 전 실제 Chrome/Edge에서 다음을 확인하세요(물리 카메라 검증은 별도 필요):

- 카메라 허용 / 거부 / 다른 앱 사용 중 / 느린 모델 로딩 / 연결 해제.
- 한 손 → 두 손 → 가렸다 다시 보여주기, 손 벌리기, 모든 튜토리얼 단계.
- 데모로 처음부터 끝까지, 튜토리얼 중 초기화, 카메라 로딩 중 데모 전환.
- 세로 사진 / 잘못된 파일 / 큰 이미지 / 다시 선택하기.
- PNG 열기, 3초 뒤 10초 영상 파일 재생, 저장 링크, 녹화 중 초기화.

## Explore 전체 컨트롤

`catalog.mjs`는 예제별 설정과 실제 조절 항목, `inputs.mjs`는 입력 선택, `toys.js`는 기존 예제의 렌더링 로직, `explorer.js`는 UI와 한 개의 Tracker/Canvas를 연결합니다. 원본 examples는 보존했습니다.

| 원본 | Explore 재구성 / 조절 항목 |
|---|---|
| 01 particles follow nose | Follow Me: 개수, 당기는 힘, 반응 거리, 미끄러짐, 최고 속도, 크기, 따라오기/도망가기/회전, 모양 |
| 02 pinch to draw | Pinch to Draw: 시작 값, 클 때/작을 때/항상 그리기, 굵기, 진하기, 선/점/지우개, 무지개, 지우기 |
| 03 mouth controls tone | Mouth Music: 파형, 낮은/높은 음, 최대 음량, 음량 입력, 음계 단계, 소리 켜기/끄기 |
| 04 two hands stretch image | Stretch It: 효과, 강도, 최소/최대 크기, 기본 회전, 위치, 이미지 |
| 05 master controls | Camera Sees: 주요/전체 점, 얼굴/손, 점 번호·크기, 테두리, 입력 크기의 동그라미 |
| 06 data flow graph | Data Flow: 입력→값→출력의 단순화된 실시간 흐름, 출력 효과, 세기, 흐르는 표시 |
| 07 text motion | Text Motion: 내 문구, 크기, 밀기/중력/꼬리, 반경·힘·출렁임·복원·감쇠·중력·회오리·입자·꼬리 조절 |
| 08 outline hover | Outline Hover: 두 줄 문구·크기, 실제 폰트 경로 변형, 반경·힘·출렁임·복원·감쇠·선 굵기·빛 번짐 |

공통 입력 15종: 두 손 거리, 한 손 엄지/검지 거리, 코/검지 거리, 입, pinch, 손 펼침, 손가락 수, 고개 기울임, 웃음, 눈썹, 손 X/Y, 코 X/Y. 포인터는 검지·pinch 가운데·코·두 손 가운데·마우스 중 선택합니다. 왼손/오른손 선택, 민감도, 반전, 부드러움과 작품색·배경색·카메라 밝기·가이드도 조절합니다.

예제별 설정과 그린 그림은 전환 중 메모리에 유지됩니다. 전체 초기화 시 지워집니다. 소리는 전환·탭 숨김·카메라 종료 시 음소거합니다. 데모는 입력 슬라이더와 무대 위 마우스/터치를 사용합니다. Face 모델은 Explore 진입 시 추가 로딩됩니다.

07은 스프링·중력·위치 기록 로직을 Canvas로 옮겼으며 GSAP 팝 트윈 대신 기본 꼬리 움직임을 사용합니다. 06의 개발자용 드래그 노드 편집기는 학생용 3단계 흐름으로 재구성했습니다. 08은 원본 M/L/Q/C/Z 경로 변형을 유지합니다. 번들 Roboto에 없는 한글은 브라우저 폰트의 글자 단위 스프링 변형으로 표시합니다. 텍스트는 24자까지입니다.

`node kids/check-explorer.mjs` — 입력 15종, 센서 없음, 좌우 반전 얼굴 기울기, 설정 분리, 모든 컨트롤 기본값, 8개 렌더링 분기 검사. 실제 기기의 카메라·오디오·녹화 재생과 시각 검증은 별도입니다.
