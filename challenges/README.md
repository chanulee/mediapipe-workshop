# 몸 챌린지 공장 · 다음 차시 교구

기존 `/kids/`와 `/studio/` 옆에 추가한 `/challenges/`입니다. 설치 없이 같은 사이트에서 실행합니다. 세로 9:16 캔버스 안에 카메라·게임·카운트다운·결과가 함께 그려지므로 사진과 10초 영상도 세로로 저장됩니다.

## 학생

1. 선생님이 보낸 **챌린지 수업 학생 링크**를 열고 이름을 적습니다.
2. 별 먹기 또는 딱 맞춰!를 고릅니다. 카메라를 켜거나 손 없이 연습합니다.
3. **도전 시작**을 누르면 3초 뒤 게임이 시작됩니다.
4. 입력(코, 손, 입, 두 손 간격 등 14종)과 반응을 연결합니다. 강도·민감도·부드러움·반대 방향도 바꿀 수 있습니다. 연결은 최대 네 개입니다. 기본 조종 연결은 유지하고 추가 연결로 크기·회전·투명도·흔들림을 바꿉니다.
5. **게임 규칙 정하기**에서 종료 조건을 고릅니다. 목표 개수는 1~50개를 슬라이더나 숫자로 입력합니다. 제한 시간은 10~120초입니다. 규칙을 바꾸면 게임은 대기 상태로 돌아갑니다.
   - **목표 개수를 채우면 성공**: 예를 들어 별 5개 또는 10개를 모으면 끝납니다. 제한 시간을 켜면 그 시간 안에 목표를 채워야 합니다. 끄면 시간 제한 없이 목표를 채울 때까지 계속합니다.
   - **시간 안에 최대한 많이**: 목표 개수는 적용하지 않습니다. 시간이 끝날 때까지 계속하고 최종 개수로 기록을 보여줍니다. ‘딱 맞춰!’에서도 시간 동안 최대한 많이 맞추는 방식으로 적용됩니다.
   캐릭터, 이미지, 색, 방해물과 게임별 난이도도 바꿀 수 있습니다. 현재 규칙은 플레이 화면과 저장 영상에도 표시됩니다.
6. **모습 바꾸기**에 **내 캐릭터 / 별 / 장애물 1·2·3 / 배경 / 게임 타이틀** 카드가 있습니다. 원하는 카드의 **이미지 넣기**에서 파일을 고르면 바로 적용됩니다. **바꾸기**로 교체하고 **삭제**로 그 자리만 지웁니다. 캐릭터·별·장애물에는 투명 배경 PNG를 사용할 수 있습니다. **배경은 세로 9:16**, **게임 타이틀은 가로 4:3** 이미지를 권장합니다. 타이틀은 게임 시작 화면과 친구 챌린지 카드에 표시됩니다. 카메라가 배경을 가리면 **화면과 카메라 설정 → 카메라 밝기**를 낮추세요. 별과 장애물은 별 먹기에서 사용합니다.
   놀이 이름과 조작 설명을 적고 **친구 챌린지에 올리기**를 누릅니다. 수정한 이미지를 친구에게 보여주려면 다시 올리기를 누르세요.
7. **챌린지 링크 복사**로 해당 게임만 바로 열리는 링크를 공유합니다. 친구에게 편집 권한이 전달되지 않습니다.
8. **친구 챌린지** 목록에서 플레이할 작품을 선택하거나 각 카드의 **링크 복사**로 부모님에게 보냅니다. 이 링크에는 편집 권한이 들어가지 않습니다. 플레이 결과는 각 기기에서만 표시되며 서버 순위표는 없습니다.

휴대폰에서는 공개 링크를 Safari 또는 Chrome으로 열고 카메라를 허용하세요. 전면 카메라를 우선 요청하며, 카메라 없이도 무대에서 손가락을 움직여 연습할 수 있습니다. 얼굴·두 손을 이용한 도전은 폰을 세워두고 떨어져서 플레이하면 편합니다. 기기 성능에 따라 인식 속도가 다르며 카카오톡 등 앱 안에서 카메라가 안 켜지면 외부 브라우저로 열어주세요. 실제 휴대폰에서의 카메라 성능은 별도 확인이 필요합니다.

별 먹기: 좌우·위아래 움직임, 캐릭터 크기, 먹이 크기, 이동 속도를 조정합니다. **게임 규칙 정하기 → 장애물 개수**에서 0~3개를 고르면 각 장애물의 규칙이 나타납니다. 1번은 **바로 게임 오버**, 2번은 **3점 감점**처럼 따로 정할 수 있습니다. 감점은 1~20점이며 점수는 0 아래로 내려가지 않습니다. 감점 후 1초 동안은 추가 감점을 막습니다. 게임 오버 장애물은 이 보호 시간 중에도 즉시 끝내며 목표 채우기·타임어택 모두 적용됩니다. 다시 도전하면 점수와 시간이 초기화됩니다.

**장애물 1~3**의 이미지 카드는 항상 보이므로 먼저 그림을 준비할 수 있습니다. 게임에 등장시키려면 장애물 개수를 늘리세요. 개수를 줄여도 이미지는 보관되며 다시 늘리면 재사용됩니다. 게임 무대에는 장애물 번호와 감점/게임 오버 규칙이 표시됩니다.

만들기 내용은 변경할 때 이 브라우저에 저장되고, 수업에서는 자동으로 서버에도 저장됩니다. **‘✓ 선생님에게도 저장됐어요’**를 확인하면 공개 전 작품도 재입장 링크로 다른 기기에서 이어 만들 수 있습니다. 같은 브라우저에서 같은 수업 주소를 새로고침하면 마지막 만들기 화면이 다시 열립니다. 이미지 적용·저장이 끝나기 전에는 화면을 닫지 마세요. 진행 중인 게임 점수는 복원하지 않습니다. 공유용 작품 링크는 공개본 플레이 화면을 열므로 편집을 이어갈 때는 학생용 수업 주소나 재입장 링크를 사용하세요.

딱 맞춰!: 그림 크기를 목표 테두리에 맞추고 정해진 시간 동안 유지합니다. 목표 크기, 허용 범위, 유지 시간, 성공 후 목표 변경 여부를 조정합니다. 첫 연결의 입력은 자유롭게 바꾸고 커지기 반응은 유지합니다.

카메라 입력을 찾지 못하면 게임 시간이 멈춥니다. 다시 찾으면 이어집니다. 브라우저가 숨겨진 동안도 게임 시간은 멈춥니다. 소리·마이크는 필요 없습니다. 카메라 영상은 서버로 전송하지 않습니다. 업로드한 그림은 기존 수업 저장소에 저장됩니다.

## 선생님

`/challenges/`에서 **선생님 · 수업 열기**로 이번 차시 전용 수업을 만드세요. 학생용 링크와 교사 전용 링크를 구분해 보관하세요. 기존 스튜디오와 같은 교사 기능(작품 확인, 피드백, 재입장 링크, 삭제/휴지통/복원)을 사용합니다. 기존 수업의 room 값을 붙여도 작동하지만 새 수업을 만들면 차시별 작품을 구분하기 쉽습니다.

수업 흐름 예시: 준비된 도전 해보기 → 아주 쉽게/어렵게 바꾸기 → 자기 챌린지 만들기 → 친구 테스트 → 난이도/설명 수정 → 다시 도전. 친구에게는 조작법을 말로 알려주기 전에 화면 설명만 보고 시도하게 해보세요.

## 로컬 실행

저장소 또는 `local-playground` 폴더에서 Node 22.13 이상으로 `node studio/local.mjs`를 실행하고 `http://127.0.0.1:8080/challenges/`를 엽니다. 서버는 스튜디오와 동일하며 저장 자료는 `.studio-data`에 남습니다. 온라인 학생에게는 localhost 대신 공개 HTTPS 주소를 보내세요.

검증: `node challenges/check.mjs`, `node studio/check.mjs`, `node studio/build.mjs`, `node studio/check-artifact.mjs`.
