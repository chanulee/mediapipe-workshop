# 몸 챌린지 공장 · 다음 차시 교구

기존 `/kids/`와 `/studio/` 옆에 추가한 `/challenges/`입니다. 설치 없이 같은 사이트에서 실행합니다. 세로 9:16 캔버스 안에 카메라·게임·카운트다운·결과가 함께 그려지므로 사진과 10초 영상도 세로로 저장됩니다.

## 학생

1. 선생님이 보낸 **챌린지 수업 학생 링크**를 열고 이름을 적습니다.
2. 별 먹기 또는 딱 맞춰!를 고릅니다. 카메라를 켜거나 손 없이 연습합니다.
3. **도전 시작**을 누르면 3초 뒤 게임이 시작됩니다.
4. 입력(코, 손, 입, 두 손 간격 등 14종)과 반응을 연결합니다. 강도·민감도·부드러움·반대 방향도 바꿀 수 있습니다. 연결은 최대 네 개입니다. 기본 조종 연결은 유지하고 추가 연결로 크기·회전·투명도·흔들림을 바꿉니다.
5. 제한 시간, 성공 횟수, 캐릭터, 이미지, 색과 게임별 규칙을 바꿉니다. 규칙을 바꾸면 게임은 대기 상태로 돌아갑니다.
6. 놀이 이름과 조작 설명을 적고 **친구 챌린지에 올리기**를 누릅니다.
7. **챌린지 링크 복사**로 해당 게임만 바로 열리는 링크를 공유합니다. 친구에게 편집 권한이 전달되지 않습니다.
8. 친구 챌린지 목록에서 선택하거나 **다음 챌린지 ↓**로 다른 공개 게임을 이어서 플레이합니다. 플레이 결과는 각 기기에서만 표시되며 서버 순위표는 없습니다.

별 먹기: 좌우·위아래 움직임, 캐릭터 크기, 별 크기, 이동 속도, 방해물 개수를 조정합니다. 방해물에 닿으면 점수가 하나 줄어듭니다. 방해물 재충돌은 1초 동안 무시합니다.

딱 맞춰!: 그림 크기를 목표 테두리에 맞추고 정해진 시간 동안 유지합니다. 목표 크기, 허용 범위, 유지 시간, 성공 후 목표 변경 여부를 조정합니다. 첫 연결의 입력은 자유롭게 바꾸고 커지기 반응은 유지합니다.

카메라 입력을 찾지 못하면 게임 시간이 멈춥니다. 다시 찾으면 이어집니다. 브라우저가 숨겨진 동안도 게임 시간은 멈춥니다. 소리·마이크는 필요 없습니다. 카메라 영상은 서버로 전송하지 않습니다. 업로드한 그림은 기존 수업 저장소에 저장됩니다.

## 선생님

`/challenges/`에서 **선생님 · 수업 열기**로 이번 차시 전용 수업을 만드세요. 학생용 링크와 교사 전용 링크를 구분해 보관하세요. 기존 스튜디오와 같은 교사 기능(작품 확인, 피드백, 재입장 링크, 삭제/휴지통/복원)을 사용합니다. 기존 수업의 room 값을 붙여도 작동하지만 새 수업을 만들면 차시별 작품을 구분하기 쉽습니다.

수업 흐름 예시: 준비된 도전 해보기 → 아주 쉽게/어렵게 바꾸기 → 자기 챌린지 만들기 → 친구 테스트 → 난이도/설명 수정 → 다시 도전. 친구에게는 조작법을 말로 알려주기 전에 화면 설명만 보고 시도하게 해보세요.

## 로컬 실행

저장소 또는 `local-playground` 폴더에서 Node 22.13 이상으로 `node studio/local.mjs`를 실행하고 `http://127.0.0.1:8080/challenges/`를 엽니다. 서버는 스튜디오와 동일하며 저장 자료는 `.studio-data`에 남습니다. 온라인 학생에게는 localhost 대신 공개 HTTPS 주소를 보내세요.

검증: `node challenges/check.mjs`, `node studio/check.mjs`, `node studio/build.mjs`, `node studio/check-artifact.mjs`.
