# 다음 차시 · 친구에게 줄 몸 놀이 만들기

지난 차시 `/kids/`는 그대로 두고, 이번 차시는 `/studio/`에서 실행합니다.

## 선생님

1. `/studio/`에서 **선생님 · 수업 열기**를 펼치고 수업 이름을 적어 새 수업을 만듭니다.
2. **학생에게 보낼 링크**만 학생에게 보냅니다. 수업마다 다른 링크가 생깁니다.
3. **교사 전용 링크 보관하기**를 펼쳐 전용 링크를 보관합니다. 학생에게 공유하지 않습니다. 이름만으로 교사 권한을 주지 않습니다.
4. 학생은 별명이나 이름으로 들어옵니다. 같은 이름도 별도 자리로 구분합니다. 한 브라우저에서는 그 수업의 자기 자리로 돌아옵니다. 학생이 링크를 잃거나 기기를 바꿨다면 해당 학생 카드의 **학생 재입장 링크**를 눌러 링크를 보내세요. 기존 작품과 피드백으로 바로 들어갑니다. 링크를 가진 사람이 그 작품을 수정할 수 있으므로 해당 학생에게만 보냅니다. 새 재입장 링크를 만들면 이전 재입장 링크는 만료되며, 원래 브라우저의 접속은 유지됩니다.
5. 교사 목록은 8초마다 갱신됩니다. 저장 시간과 입력→반응 연결을 확인하고 **현재 작품 열기**로 저장된 설정을 실행합니다. 카메라 영상이나 학생의 실제 몸 움직임을 원격 감시하는 기능은 없습니다.
6. 작품을 열면 교사가 자기 카메라 또는 데모로 실행하고 **한마디 보내기**로 피드백합니다. 학생의 **도착한 한마디**에 표시됩니다.
7. 오래된 작품은 학생 카드의 **작품 삭제**로 정리합니다. 학생·친구 목록에서 사라지고 수정도 차단됩니다. **휴지통 → 복원**으로 원래 설정과 피드백을 되살릴 수 있습니다. 공개된 작품을 복원하면 친구 목록에도 다시 나타납니다.

## 학생 경험

1. 이름 또는 별명 입력 → **내 놀이 만들기**.
2. 준비된 프리셋 7개를 직접 해봅니다. 그림·알갱이·그리기·소리·글자 예제의 렌더러와 센서를 재사용합니다.
3. **내가 무엇을 움직이면? → 얼마나·반대로·부드럽게 → 무엇이 변할까?**를 고릅니다.
4. 처음에는 연결 하나, 필요하면 **움직임 하나 더 연결하기**로 최대 두 개를 연결합니다. 같은 출력은 중복 선택하지 않습니다.
5. **이미지 선택 → 미리보기 → 이미지 적용**으로 내 이미지를 넣습니다. 선택만으로는 작품이 바뀌지 않습니다. **업로드한 이미지 삭제**로 작품에서 제거합니다. 글자·색과 **더 바꿔보기**의 상세 설정도 조절합니다.
6. 놀이 이름과 **친구야, 처음엔 이렇게 해봐!** 한 문장을 적습니다.
7. **플레이해보기**로 편집 패널을 숨겨 직접 테스트하고 **편집으로 돌아가기**로 돌아옵니다.
8. **친구 놀이에 올리기**를 눌러 공개합니다. 이후 편집은 만드는 중 버전에 자동 저장되며, 다시 올려야 친구에게 반영됩니다.
9. **친구 놀이**에서 다른 작품을 열면 친구의 설정과 이미지가 내 카메라로 실행됩니다. 친구에게 한 문장 피드백을 보냅니다.

입력 14종: 두 손 간격, 엄지·검지 간격, 코·손 거리, 입 벌리기, 손가락 붙이기, 손 펼치기, 편 손가락 수, 고개 기울이기, 웃기, 눈썹, 손 좌우·위아래, 코 좌우·위아래.

출력: 각 장난감 고유 반응(알갱이·그리기·음높이·글자 등), 크기, 회전, 나타나기, 흔들림. 크기·회전 등은 그림 외 장난감에도 연결됩니다. ‘작품이 따라갈 위치’는 별도로 선택하며 기본값은 프리셋에 맞춰져 있습니다.

카메라가 안 되면 **손 없이 해보기**에서 연결별 슬라이더와 무대 위 마우스로 참여할 수 있습니다. 사진과 10초 영상 저장도 기존 기능을 사용합니다. 음향은 **소리 켜기**를 눌러야 시작됩니다.

## 데이터와 공유

설정·별명·피드백은 수업 저장소(D1), 선택한 그림은 파일 저장소(R2)에 저장합니다. 카메라·마이크 영상은 서버로 보내지 않습니다. 학생 링크를 가진 사람이 공개 작품을 볼 수 있으므로 별명과 공유 가능한 그림을 사용합니다. 교사 링크는 비공개 초안과 피드백에 접근하는 열쇠입니다. 학생 수정 권한은 이름이 아닌 브라우저에 저장된 임의의 열쇠로 구분합니다.

혼자 해보기는 브라우저에만 저장됩니다. **내 놀이 파일 저장 / 불러오기**로 기기 간 옮기거나 백업할 수 있습니다. 학생·교사 사이 공유에는 선생님이 만든 수업 링크가 필요합니다. 네트워크 오류 시 변경은 브라우저에 보관하고 재시도하며, 저장을 마치기 전에 탭을 닫으면 경고합니다.

## 로컬 실행

Node.js 22.13 이상(권장 24 이상)이 필요합니다. 패키지 설치는 없습니다.

저장소 루트에서:

```sh
node studio/local.mjs
```

`local-playground` 폴더만 복사해도 같은 명령으로 실행할 수 있습니다.

브라우저에서 `http://127.0.0.1:8080/studio/`를 엽니다. 이전 교구는 `http://127.0.0.1:8080/kids/`입니다. 데이터는 해당 폴더의 `.studio-data/`에 남습니다. 로컬 데이터와 공개 Sites 데이터는 별개입니다. 이 로컬 주소는 같은 컴퓨터에서 테스트하는 용도이며, 온라인 학생에게는 공개 Sites 수업 링크를 보냅니다.

## 개발·검사

```sh
node studio/check.mjs
node studio/build.mjs
```

Sites는 기존 project_id를 그대로 사용합니다. 기존 `/kids/` 파일은 변경하지 않고, Worker가 같은 파일을 제공하면서 `/studio/`와 `/api/`를 추가합니다. D1 마이그레이션은 `drizzle/0000_studio.sql`, 호스팅 구성은 `.openai/hosting.json`입니다.
